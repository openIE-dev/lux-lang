# component-tour

A small tour of Lux's component features: props, slots, scoped styles, conditional rendering, list rendering.

```bash
openie-lux run Tour.lux
```

What this shows:
- Component composition
- Props with typed defaults
- Scoped `style:` blocks compiled to `[data-lux-scope="..."]` selectors
- `if`/`for` in view blocks
